# Native verification experiments

The constructor owns model inputs. Simulate selects the observation population and measurement plan. Results retains the pinned model, measurements, execution policy, producer identities and diagnostic evidence. The verification workspace appears for a selected saved run in Simulate and Results; it reads that run's verified graph rather than the current editor draft. Catalogue actions open the corresponding tool.

## Settlement and feature evidence

The Metrics Sink can round the whole round award before WinCap. Its quantum is an exact decimal rational, with floor, ceiling, nearest-even and nearest-away modes. Both interpreters retain `__settlementBefore`, `__settlementAfter` and `__roundingDifference` in payout units; the final award applies the cap afterward. Enabling rounding is a model change and changes its identity.

Episode collectors keep nested parent/episode identities and child ordinals. The configurable first 1–16 child values produce ordinal moments and paired cross-ordinal covariance. Pairs condition on both ordinals being reached; missing children are not zero payouts. Profiles respect entry cohorts, filters and the shared bounded measurement-storage budget. Replay witnesses retain the identities. Completed loops record condition, modelLimit, payoutCap or authoredStop according to the authored typed exit expression. Budget interruptions retain a resourceExpiry subset of cancelled feature boundaries. Interrupted rounds never contribute partial payouts.

## Parameter and policy experiments

Create named arms for initial numeric state, draw weight, WinCap, loop cap, financial execution parameters or session policies. Every arm is compiled and validated before child runs are admitted. The write-ahead manifest records the baseline version, measurement plan, execution options, samples, seeds and perturbations. Child runs use ordinary run execution, archive, socket delivery and replay. Arms execute serially with distinct deterministic seeds; they are not a common-random-number paired design.

Reports show mean, event and configured tail deltas, local finite-difference derivatives for numeric parameters, independent-run uncertainty where justified, and variance-based observation planning. Session payout/turnover is a paired ratio using actual costs. Ordinary round intervals are withheld for retained-state and early-stopped populations. Zero empirical variance does not certify precision. Planning and normal intervals are approximate, with a declared confidence family; they do not certify an unobserved rare tail or global derivative.

Admission is bounded to eight variants, ten million aggregate planned slots, two active experiments and one thousand retained manifests. The process is the single encrypted snapshot writer. Accepted mutations are not automatically retried after an ambiguous response. Cancellation closes never-started arms as well as the current job. Restart marks unfinished experiments interrupted; retained results remain available, and explicit replay creates a new identity rather than silently resuming RNG state.

## Verified finite sampling design

The tool accepts exact finite atoms with reward, target probability, proposal probability and optional stratum. It verifies normalization and target support coverage, derives likelihood ratios itself, and actually samples the proposal using exact integer categorical draws. Importance and fixed-allocation stratified designs retain observed atoms, reward/event estimates, exact reference values, exact design variance and weight diagnostics. Each stratum needs at least two samples, allocations must sum to the declared total, and the calculation is bounded to 128 atoms, 32 strata and one million observations.

This proves likelihood/support properties for the supplied finite design. It does not establish a likelihood contract for arbitrary graph expressions or certify that an authored finite law matches a commercial game. Empirical intervals are approximate and withheld when observed variance is zero. Stratified rows expose conditional likelihood weights separately from global p/q.

## Resource-stop reference

Supply a substochastic transient transition matrix and per-visit rewards; missing row mass means absorption. Rewards occur before transitions. Exact propagation calculates survival probability and retained reward/duration through the declared horizon. The uncapped Markov reference supplies the remaining expected reward when it is finite. Divergent references report the unresolved reward explicitly. This is a model-level bound, not an inference from elapsed runtime or a timeout. Limits are 32 states, 4,096 steps and one million transition operations (the table editor supports eight states).

## RNG and session populations

Opt-in raw RNG auditing records actual consumed words, including rejection draws, without advancing the generator. A bounded audit of at most 65,536 logical streams reports duplicate initial states, four-word prefixes and equal-length full transcript digest candidates. Distinct SplitMix64 expansion seeds have distinct first xoshiro256** output words because the relevant transformations are bijective; the scheduled initial-word duplication probability is therefore zero or one. The separate ideal independent 256-bit prefix collision bound is a reference null, not proof that the seeded PRNG produces independent random streams. A digest match remains a collision candidate.

Sessions execute fixed horizon, ruin, profit target, loss limit or first-feature policies. Thresholds and feature metric identity are pinned. Unplayed slots preserve deterministic replay coordinates but are not zero-valued observations. Duration, stopping classification, actual payout and turnover are collected on complete independent sessions. Initial inability to fund a round is a valid zero-duration ruin session. Interrupted sessions remain censored and distinct from completed stops.

## External evidence inputs

Build → Data / AST → Rule / spec / asset inputs stores kind, identity, version, SHA-256 and optional URI or embedded bytes. The compiler checks embedded bytes against the digest and bounds total size; the manifest is included in graph hashing, retained with runs and exportable. External URI/digest entries without bytes remain authored assertions. The server does not fetch external URIs. Existing graphs with absent optional evidence, settlement and loop-exit fields keep their prior canonical identities.

Independent fixtures live in `VerificationMilestoneTests.cs`, `VerificationExperimentApiTests.cs` and `unit/session-policies.spec.ts`. One critical browser workflow proves constructor settlement/evidence editing, execution, finite sampling/resource calculations, automatic experiments and reload. Mathematical edge cases stay below the browser layer.

The generator implementation and its seed expansion are checked against the authors' [PRNG reference and source](https://prng.di.unimi.it/) and [scrambled linear generator paper](https://vigna.di.unimi.it/ftp/papers/ScrambledLinear.pdf). The first-word collision statement above is an algebraic property of this implementation's seed schedule, rather than an empirical independence claim.
