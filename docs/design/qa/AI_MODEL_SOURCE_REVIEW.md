# AI model source and private candidates

## Behavior

Generation admits the complete canonical response, validates it with the real compiler and opens an independent private project. It preserves state, nested mechanics, AST, ports and unknown metadata instead of rebuilding a partial graph or appending nodes to the current game. Original JSON numbers are checked before browser conversion. Invalid responses leave the original project available.

Auto-tune submits the complete current canonical model. Its report retains the target from that request; editing the next target does not relabel a previous candidate. Opening the candidate creates a separate project. The response provides no sample count or confidence interval, so the UI labels RTP as a reported candidate value and supplies no fabricated provenance badge. A report does not certify the current draft.

Both operations abort on unmount/source changes and discard obsolete responses. Generation also guards the compiler-validation phase. The native modal wraps keyboard focus, restores the trigger on Escape, permits cancellation while waiting and fits the four captured viewports. Inspected WebKit phone and Firefox desktop captures showed a dark heading; explicit inherited text color corrected it, and the refreshed WebKit phone capture was inspected.

Explicit save payloads, including fallback payloads, now pass the numeric budget guard before POST/PUT. The existing browser save/open scenario remains operational; a dedicated malicious explicit-payload hook test is not claimed.
